# Job Application Tracker

A web app to track job applications: add, view, update and delete entries.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: Supabase (PostgreSQL)

## Features
- Add new job applications
- View all applications
- Update status
- Delete applications

## Setup
1. Clone the repo
2. cd backend and run npm install
3. Create a .env file with your Supabase URL and key
4. Run node server.js
5. Open frontend/index.html in the browser
